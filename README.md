### 👨‍💻 About

I build **production systems end to end** — from GPU-accelerated media pipelines and real-time streaming to a from-scratch motion-graphics engine, the distributed infrastructure that runs it all, and the web apps on top. I like hard problems at the boundary of **performance, graphics, and systems**, and I ship them: live products with real users, not demos.

- 🎥 **Real-time media & streaming** — WebRTC, HLS/LL-HLS, FFmpeg, NVENC/NVDEC, adaptive bitrate, OBS-style compositing
- 🎨 **Graphics engines** — a from-scratch Rust compositor/renderer (CPU + GPU path tracing via `wgpu`) targeting After Effects–class capability
- 🖥️ **Distributed & remote systems** — browser-delivered desktops, multi-server orchestration, self-hosted platforms
- 🌐 **Full-stack web** — React / TypeScript / Node, SSE-driven live dashboards, auth & SSO, clean APIs
- ⚙️ **DevOps** — Docker, nginx, TLS, CI/CD, GPU hosts, monitoring, zero-drama deploys

🟢 **Currently open to senior / staff engineering roles** in media, streaming, graphics, or systems.<br/>
⚡ **8,500+ contributions in the last year** — I ship, daily.

### 🚀 Featured work

| Project | What it is | Stack |
|---|---|---|
| **[Heddle](https://heddle.hiradnikoo.com)** | A from-scratch motion-graphics & compositing engine — masks, effects, 3D/2.5D, a built-in **path tracer** (BVH + GI, GPU via wgpu), and its own scene language. Aims at After Effects / Blender–class rendering. | Rust, wgpu, WASM |
| **[Nixosoft Platform](https://openc.hiradnikoo.com)** | A self-hosted application platform & web desktop — SSO, containerized apps, full Linux desktops in the browser. | Rust, Docker, nginx |
| **WebStation** | Low-latency browser-delivered remote desktop over **WebRTC** with adaptive FEC & encoder bitrate control and a live Chromium UI. | C++, GStreamer, WebRTC |
| **[CustomHLSStreamer](https://github.com/hiradnikoo/CustomHLSStreamer)** | Production Node.js service for customizable live **HLS** streams with real-time content updates. | Node.js, FFmpeg, ZeroMQ |
| **[media-stream-orchestrator](https://github.com/hiradnikoo/media-stream-orchestrator)** | A headless, OBS-like library: multiple scenes, layered sources, and streaming — no UI. | Node.js, FFmpeg |
| **[Nixosoft](https://nixosoft.com)** | My software studio — the umbrella for the products above. | — |

> Much of my recent systems and engine work ships through private repos; the links above are the public-facing products. Happy to walk through architecture on request.
